# @ligneous/album-generated-queries

Prisma-backed helpers to **collect and count** media for generated (virtual) GEDCOM albums: sources, dates, events, families, and individuals.

Depends on `@ligneous/album-view` and `@ligneous/prisma`. In the monorepo these are `file:` paths to sibling packages; if you clone this repo alone, point those dependencies at local checkouts or published builds.
